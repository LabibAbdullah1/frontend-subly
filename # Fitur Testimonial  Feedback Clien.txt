# Fitur Testimonial / Feedback Client

Membangun sistem feedback lengkap: client mengisi testimonial dari dashboard mereka, admin mereview dan memilih mana yang tampil di landing page, landing page menampilkan testimonial yang sudah disetujui dalam tampilan yang menarik.

## Alur Sistem

```
Client (punya subdomain aktif)
  → Isi form feedback di dashboard (rating + judul + komentar)
  → Tersimpan di DB dengan status "pending"
       ↓
Admin Panel
  → Lihat semua testimonial masuk
  → Approve / Reject / Feature (tampilkan di landing page)
       ↓
Landing Page
  → Tampilkan testimoni yang status = "featured" atau "approved"
  → Carousel/grid animasi yang cantik
```

### Database — Prisma Schema

#### [MODIFY] [schema.prisma](file:///d:/backup/DATA%20LABIB/PROJECT%20BISNIS/subly-JS/backend/prisma/schema.prisma)

Tambah model `Testimonial`:

```prisma
model Testimonial {
  id          BigInt    @id @default(autoincrement()) @db.UnsignedBigInt
  userId      BigInt    @map("user_id") @db.UnsignedBigInt
  user        User      @relation(fields: [userId], references: [id])
  subdomainId BigInt?   @map("subdomain_id") @db.UnsignedBigInt
  rating      Int       @default(5) @db.TinyInt       // 1–5
  title       String    @db.VarChar(255)
  content     String    @db.Text
  status      TestimonialStatus @default(pending)      // pending | approved | featured | rejected
  adminNote   String?   @map("admin_note") @db.Text
  createdAt   DateTime? @default(now()) @map("created_at")
  updatedAt   DateTime? @updatedAt @map("updated_at")
  deletedAt   DateTime? @map("deleted_at")

  @@map("testimonials")
}
```

Juga tambah `testimonials` relation ke model `User`.
